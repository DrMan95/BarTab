# BarTab

Instructions

1. Find your IP from CMD. Open CMD and type ipconfig. There you will find your ipv4 ip, for example 192.168.1.113
2. When pressing the play button from visual studio, the site will open. The link will be something like 

http://192.168.1.113:5123

The port (5123) be tweaked from Properties/launchSettings.json. The port is static but the IP is dynamic

3. From your phone, dont type localhost since this is for the PCs. Type the whole like as above and you will be synced.
Make sure that ALL devices are on the same network, otherwise it won't work
